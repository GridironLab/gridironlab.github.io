# Gridiron Lab

Pronósticos de la NFL con el modelo **GL**, siempre comparados contra Las Vegas.

**App:** https://gridironlab.github.io (en el cel: "Agregar a pantalla de inicio").

Esta carpeta se publica sola todos los días: el código del modelo genera `index.html`
con los datos del día, pasa la revisión (`verificar.py`) y solo entonces se sube aquí.
No edites `index.html` a mano: se sobrescribe en cada actualización.
